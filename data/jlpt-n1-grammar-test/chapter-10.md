# N1文法問題演習

## [1]

**1 この仕事はだれが（   ）と、大差ない。**
- a するよう
- b しよう
- c するだろう
- **[正解: b]**
- **[タグ: ～（よ）うと（も）・～（よ）うが]**

**2 母は、どんなに（   ）が、払うべき金は払ってくれた。**
- a 高いだろう
- b 高かろう
- c 高かったろう
- **[正解: b]**
- **[タグ: ～（よ）うと（も）・～（よ）うが]**

**3 母がどんなに説得しようが、父は（   ）。**
- a 考えをよく説明した
- b その都度考え直した
- c 考えを変えなかった
- **[正解: c]**
- **[タグ: ～（よ）うと（も）・～（よ）うが]**

**4 どんなに便利なものだろうと、（   ）。**
- a 要らないものは買いたくない
- b 要らないものもかってしまう
- c 要るものは買う
- **[正解: a]**
- **[タグ: ～（よ）うと（も）・～（よ）うが]**

**5 この先何があろうと、（   ）。**
- a わたしは心配だ
- b 心配するな
- c 心配ではないのか
- **[正解: b]**
- **[タグ: ～（よ）うと（も）・～（よ）うが]**
