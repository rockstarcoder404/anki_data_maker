# N1文法問題演習

## [1]

**1 内容が高度（   ）こそ、わかりやすく説明する必要がある。**
- a だったらば
- b であれば
- c であったらば
- **[正解: b]**
- **[タグ: ～ばこそ]**

**2 忙しければこそ、（   ）のだ。**
- a ご飯を食べる時間もない
- b 旅行には行けない
- c 時間の使い方の上手くなる
- **[正解: c]**
- **[タグ: ～ばこそ]**

**3 収入が少なければこそ、（   ）のだ。**
- a 暮らせない
- b 楽しくない
- c 楽しく暮らす努力をする
- **[正解: c]**
- **[タグ: ～ばこそ]**

**4 わたし達二人の関係が良ければこそ、（   ）。**
- a 言いたいことを自由に言えるんですね
- b 一緒に暮らしてみませんか
- c はっきり意見を言ってください
- **[正解: c]**
- **[タグ: ～ばこそ]**

**5 あなたのことを思えばこそ、（   ）。**
- a あなたの気持ちがわからないのです
- b あなたの気持ちをよく説明してください
- c あなたのことに干渉するのですよ
- **[正解: c]**
- **[タグ: ～ばこそ]**
