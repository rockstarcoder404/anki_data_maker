# N1文法問題演習

## [1]

**1 林先生が（   ）にひきかえ、山田先生は物わかりがいい。**
- a 頑固
- b 頑固なの
- c 頑固な
- **[正解: c]**
- **[タグ: ～にひきかえ]**

**2 国にいたころは遊んでばかりいたのにひきかえ、日本では（   ）。**
- a あまり遊ばない
- b まじめに勉強している
- c 全然変わらない
- **[正解: b]**
- **[タグ: ～にひきかえ]**

**3 母が（   ）であるのにひきかえ、父は（   ）だ。**
- a 関西地方出身・東北地方出身
- b 58歳・52歳
- c 穏やか・感情的
- **[正解: c]**
- **[タグ: ～にひきかえ]**

**4 （   ）にひきかえ、（   ）。**
- a 去年・今年の収入の減少はひどいものだ
- b 今年・来年の収入の減少はひどいものだろう
- c 来年・再来年以降の収入の減少はひどいものかもしれない
- **[正解: a]**
- **[タグ: ～にひきかえ]**

## [2]

**1 みち子の成績が下がったことにもまして、あの子の（   ）。**
- a 生活態度が心配だ
- b 病気が良くなったことがうれしい
- c 性格が明るいことが安心だ
- **[正解: a]**
- **[タグ: ～にもまして]**

**2 孫たちの顔を見ることが、祖父にとっては何にもまして（   ）。**
- a 楽しみではないらしい
- b 楽しみらしい
- c 楽しくないことらしい
- **[正解: b]**
- **[タグ: ～にもまして]**

**3 （   ）にもまして、（   ）は仕事が多い。**
- a いつもの年・今年
- b 水曜日・木曜日
- c カンさん・リンさん
- **[正解: a]**
- **[タグ: ～にもまして]**

## [3]

**1 昨日はあらしとは（   ）までも、大風が吹いた。**
- a 言う
- b 言える
- c 言わない
- **[正解: c]**
- **[タグ: ～ないまでも]**

**2 （   ）までも、歌を歌う仕事をしたい。**
- a 歌が上手にはならない
- b 人気歌手にはなれない
- c カラオケには行かない
- **[正解: b]**
- **[タグ: ～ないまでも]**

**3 一流大手の会社には入れないまでも、せめて中企業には（   ）。**
- a 就職したい
- b 就職できない
- c 就職したくない
- **[正解: a]**
- **[タグ: ～ないまでも]**

**4 ベスト４とはいかないまでも、（   ）。**
- a 優勝はしたい
- b ベスト８には入ってほしい
- c 準優勝はしたい
- **[正解: b]**
- **[タグ: ～ないまでも]**
