# N1文法問題演習

## [1]

**1 親の涙を（   ）に至って、僕は自分がやってきたことを反省した。**
- a 見る
- b 見た
- c 見たこと
- **[正解: a]**
- **[タグ: ～に至って・～に至っても]**

**2 決定的な証拠が見つかるに至って、犯人は（   ）。**
- a まだ見つからない
- b 背の高い男のようだ
- c ようやく罪を認めた
- **[正解: c]**
- **[タグ: ～に至って・～に至っても]**

**3 犠牲者が出る（   ）問題の深刻さに気がつくのでは遅いのだ。**
- a に至って
- b に至っては
- c に至っても
- **[正解: a]**
- **[タグ: ～に至って・～に至っても]**

**4 （   ）に至っても、政府は交渉のやり方の不適切さに気づかない。**
- a ３度も交渉に失敗する
- b 初回の交渉に失敗する
- c 交渉を始める
- **[正解: a]**
- **[タグ: ～に至って・～に至っても]**

## [2]

**1 どの世代でも読書離れが目立つ。20代の若者（   ）新聞さえ読まないようだ。**
- a に至って
- b に至っては
- c に至る
- **[正解: b]**
- **[タグ: ～に至っては]**

**2 不況で就職は厳しくなっている。ある大学に至っては就職内定率が（   ）そうだ。**
- a 昨年より少し低下した
- b 昨年と同じくらいだった
- c 昨年の３分の２だった
- **[正解: c]**
- **[タグ: ～に至っては]**

## [3]

**1 弟の子供たちは甘やかされて育ち、今では親に（   ）始末だ。**
- a 命令する
- b 命令した
- c 命令の
- **[正解: a]**
- **[タグ: ～始末だ]**

**2 後輩のためと思ってあれこれ教えてあげたのだが、（   ）始末だ。**
- a もう知っている
- b おせっかいと言われる
- c 感謝される
- **[正解: b]**
- **[タグ: ～始末だ]**

**3 うちの息子はどうしようもない。何をやってもうまくいかず、ついに（   ）始末だ。**
- a アルバイトを探し始める
- b アルバイトでお金を稼ぐ
- c アルバイトも辞めさせられる
- **[正解: c]**
- **[タグ: ～始末だ]**

- **[正解: b]**
- **[タグ: ～っぱなっしだ]**

**3 彼は仕事を他人に任せっぱなしで、自分では（   ）。**

- c 意見を待っている
- **[正解: b]**
- **[タグ: ～っぱなっしだ]**

**4 久しぶりに会った友達と、朝まで（   ）だった。**

- **[タグ: ～っぱなっしだ]**
