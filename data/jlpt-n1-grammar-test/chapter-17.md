# N1文法問題演習

## [1]

**1 これからは（   ）たりとも練習を怠けてはいけませんよ。**
- a １日
- b 毎日
- c １週間
- **[正解: a]**
- **[タグ: ～たりとも…ない]**

**2 わたしたちの税金なので、（   ）たりとも無駄にしてほしくない。**
- a １万円
- b １千円
- c １円
- **[正解: c]**
- **[タグ: ～たりとも…ない]**

**3 リサイクルできるものは、かん１本たりとも（   ）。**
- a 捨ててしまった
- b 捨てられない
- c 大切にしたい
- **[正解: b]**
- **[タグ: ～たりとも…ない]**

**4 あしたは13時の新幹線に乗ります。１分たりとも（   ）。**
- a 遅れないように
- b 遅れたらどうしよう
- c 遅れたら次の新幹線に乗りなさい
- **[正解: a]**
- **[タグ: ～たりとも…ない]**

## [2]

- **[正解: c]**
- **[タグ: ～すら]**

- b 頑張れば十分だ

- **[タグ: ～すら]**

- b 息をすることすら
- c 息をすることですら

- **[タグ: ～すら]**

**4 あとは皿に盛り（   ）すれば、この料理は完成だ。**
- a さえ
- b すら
- c こそ
- **[正解: a]**
- **[タグ: ～すら]**
