# N1文法問題演習

## [1]

**1 このニュースは特に重要ではないから、（   ）までもない。**
- a みんなが知っている
- b 急いでみんなに知らせる
- c すぐに忘れる
- **[正解: b]**
- **[タグ: ～までもない]**

**2 今さら（   ）までもなく、日本は少子高齢化が進んでいる。**
- a 説明する
- b 説明しない
- c 説明が必要な
- **[正解: a]**
- **[タグ: ～までもない]**

**3 サッカー好きの彼が試合のあったその日、どこで何をしていたか、（   ）までもない。**
- a 見つける
- b わかる
- c 聞く
- **[正解: c]**
- **[タグ: ～までもない]**

## [2]

**1 もしＴ大学の入学試験に失敗したら、（   ）までだ。**
- a 親にしかられる
- b 来年また挑戦する
- c 親に経済的負担がかかる
- **[正解: b]**
- **[タグ: ～までだ・～までのことだ]**

**2 考えても答えがわからなければ、（   ）までのことだ。**
- a 解答欄を空白にしておく
- b 解答欄には何も書かない
- c 解答欄に何か書く必要はない
- **[正解: a]**
- **[タグ: ～までだ・～までのことだ]**

**3 ちょっと聞き取れなかったので（   ）までです。誤解しないでください。**
- a 聞き返す
- b 聞き返している
- c 聞き返した
- **[正解: c]**
- **[タグ: ～までだ・～までのことだ]**

**4 近くまで来る用事があったから、（   ）までです。**
- a わざわざ顔を見に来た
- b おいしいケーキを作ってきた
- c ちょっと寄った
- **[正解: c]**
- **[タグ: ～までだ・～までのことだ]**

## [3]

**1 どれだけ夜遅くまで勉強しても、試験中に（   ）それまでですよ。**
- a 居眠りすれば
- b 起きていられれば
- c 頑張れば
- **[正解: a]**
- **[タグ: ～ばそれまでだ]**

**2 旅行の時にビデオカメラを持って行っても、（   ）それまでだ。**
- a 充電していなければ
- b 帰宅後すぐに見る気がなければ
- c 重ければ
- **[正解: a]**
- **[タグ: ～ばそれまでだ]**

**3 花束は（   ）それまでだが、ワイングラスのような物なら記念品として適当なのではないか。**
- a 飾ってしまえば
- b 見てしまえば
- c 枯れてしまえば
- **[正解: c]**
- **[タグ: ～ばそれまでだ]**

## [4]

**1 彼があの時怒ったことを（   ）には当たらない。あんなひどいことを言われれば当然だ。**
- a 忘れる
- b 思い出す
- c 非難する
- **[正解: c]**
- **[タグ: ～には当たらない]**

**2 自分の気持ちを親に理解してもらえなかったからといって、（   ）には当たりません。これから何度でも話し合いを重ねればいいのです。**
- a 嘆く
- b 嘆いた
- c 嘆いている
- **[正解: a]**
- **[タグ: ～には当たらない]**

**3 彼のスピーチは（   ）には当たらない。ほかの人の意見をそのまま述べているだけだ。**
- a 録音する
- b 感心する
- c もう一度聞く
- **[正解: b]**
- **[タグ: ～には当たらない]**

## [5]

- c 子供が大切でなくて
- **[正解: a]**
- **[タグ: ～でなくてなんだろう（か）]**

**2 新しい生命を人間がつくり出す。これが（   ）でなくてなんであろうか。**

- **[正解: a]**
- **[タグ: ～でなくてなんだろう（か）]**

**3 もう治らないと言われた目が見えるようになった。これが（   ）でなくてなんだろう。**

- **[正解: c]**
- **[タグ: ～でなくてなんだろう（か）]**

## [1〜5]

- **[タグ: 総合演習]**
