# N1文法問題演習

## [1]

**1 その宇宙飛行士の講演会は（   ）を皮切りに、130か所で行われた。**
- a 北海道
- b 外国
- c 全国
- **[正解: a]**
- **[タグ: ～を皮切りに（して）・を皮切りとして]**

**2 この選手は昨年の地区大会入賞を皮切りに、（   ）。**
- a ますます練習に励んでいる
- b 今年も入賞が期待される
- c いくつもの大会で好成績を残している
- **[正解: c]**
- **[タグ: ～を皮切りに（して）・を皮切りとして]**

**3 山田さんの発言を皮切りにして、（   ）。**
- a 皆さんが意見を言ってください
- b みんなが次々に意見を言った
- c 川田さんも意見を言った
- **[正解: b]**
- **[タグ: ～を皮切りに（して）・を皮切りとして]**

**4 中川さんは10年前の個展を皮切りとして、（   ）。**
- a いろいろなところで個展を開いている
- b その後2度個展を開いた
- c 1度も個展を開いていない
- **[正解: a]**
- **[タグ: ～を皮切りに（して）・を皮切りとして]**

**5 わたしは退職の記念旅行を皮切りとして、（   ）。**
- a 旅行が老後の趣味になった
- b 国内、国外にあちこち旅行している
- c 旅行会社に勤め始めた
- **[正解: b]**
- **[タグ: ～を皮切りに（して）・を皮切りとして]**
