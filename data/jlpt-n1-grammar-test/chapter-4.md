# N1文法問題演習

## [1]

**1 あの部屋はかなり寒いから、長い時間いるなら上着なり（   ）なりが必要だろう。**
- a 暖房をつける
- b ひざ掛け
- c 防寒
- **[正解: b]**
- **[タグ: ～なり…なり]**

**2 着ない服は人にあげるなりフリーマーケットに出すなりして、（   ）。**
- a 整理した
- b 整理したことがある
- c 整理しよう
- **[正解: c]**
- **[タグ: ～なり…なり]**

**3 1年に2、3度、ハイキングなりキャンプなり遊びに（   ）。**
- a 行きませんか
- b 行きました
- c 行くことに決まった
- **[正解: a]**
- **[タグ: ～なり…なり]**

**4 電話なりメールなり（   ）。**
- a どちらでお知らせしますか
- b 知らせる方法はあるはずですよ
- c 知らせる方法が何もない
- **[正解: b]**
- **[タグ: ～なり…なり]**
