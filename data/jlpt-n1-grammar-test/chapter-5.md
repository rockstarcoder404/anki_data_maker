# N1文法問題演習

## [1]

**1 （   ）いかんで入院するかしないかを決めるのだそうです。**
- a 本人の承諾
- b 空きベッドの有無
- c 今日の検査の結果
- **[正解: c]**
- **[タグ: ～いかんだ]**

**2 父は、体調いかんでは、（   ）。**
- a 役職を続けるかどうか迷っているらしい
- b その日の仕事の量をかえているようだ
- c 会社を辞めるかもしれない
- **[正解: c]**
- **[タグ: ～いかんだ]**

**3 宣伝方法いかんで（   ）。**
- a 商品が売れた
- b 売り上げが左右される
- c 売り上げ数が減った
- **[正解: b]**
- **[タグ: ～いかんだ]**

**4 党首のやる気いかんで（   ）。**
- a 選挙の結果が決まる
- b 選挙に負けた
- c 選挙に勝ちたい
- **[正解: a]**
- **[タグ: ～いかんだ]**

- **[タグ: ～いかんにかかわらず／～いかによらず・～いかんを問わず]**

**4 借りたお金は金額いかんにかかわらず、（   ）。**
