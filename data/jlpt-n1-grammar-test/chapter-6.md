# N1文法問題演習

## [1]

**1 うちの犬は、自分もこの家の家族の一人だと（ ）の顔をしてテレビを見ている。**
- a 言うばかり
- b 言わんばかり
- c 言わないばかり
- **[正解: b]**
- **[タグ: ～んばかりだ]**

**2 ニュースを聞いて、彼は（ ）驚いた。**
- a 飛び上がらんばかりに
- b 飛び上がると言わんばかりに
- c 飛び上がれんばかりに
- **[正解: a]**
- **[タグ: ～んばかりだ]**

**3 今にも（ ）子を置いて、母親はどこへ行ってしまったのだろう。**
- a 泣き出さんばかりに
- b 泣き出さんばかりの
- c 泣き出さんばかりな
- **[正解: b]**
- **[タグ: ～んばかりだ]**

**4 彼女はその人の死を知って、（ ）声を上げて泣いた。**
- a みんなに聞こえんばかりの
- b 涙があふれんばかりの
- c のどが張り裂けんばかりの
- **[正解: c]**
- **[タグ: ～んばかりだ]**

- c 「わあ、いっぱい」
- **[正解: b]**
- **[タグ: ～とばかり（に）]**
