# N1文法問題演習

## [1]

**1 運動がてら（   ）。**
- a 運動場まで行ってきた
- b 犬の散歩に出かけた
- c 毎日３キロ走っている
- **[正解: b]**
- **[タグ: 〜がてら]**

**2 （   ）図書館に行った。**
- a 買い物がてら
- b 本を借りがてら
- c 本を探しながら
- **[正解: a]**
- **[タグ: 〜がてら]**

**3 （   ）車の展示場をのぞいた。**
- a いい車を見つけがてら
- b 急ぎがてら
- c 遊びがてら
- **[正解: c]**
- **[タグ: 〜がてら]**

## [2]

**1 （   ）かたがた近いうちに恩師を訪ねようと思っている。**
- a 訪問
- b 食事
- c 就職の報告
- **[正解: c]**
- **[タグ: 〜かたがた]**

**2 （   ）かたがた、お宅に伺います。**
- a ごあいさつ
- b 休日
- c おじゃま
- **[正解: a]**
- **[タグ: 〜かたがた]**

**3 叔母が体調を崩したと聞いたので、見舞いかたがた（   ）。**
- a 手伝った
- b 手伝いに行った
- c 果物を贈った
- **[正解: b]**
- **[タグ: 〜かたがた]**

## [3]

**1 彼は（   ）のかたわらNPOの活動をしている。**
- a 一人暮らし
- b 創作活動
- c 趣味
- **[正解: b]**
- **[タグ: 〜かたわら]**

**2 母は（   ）かたわら翻訳の仕事もしている。**
- a 数学を教える
- b 夕飯を作る
- c 音楽を聞く
- **[正解: a]**
- **[タグ: 〜かたわら]**

**3 山中さんは市役所に勤めるかたわら（   ）。**
- a 歌手としても活躍している
- b いつも忙しくしている
- c 家では年を取った親の世話をしている
- **[正解: a]**
- **[タグ: 〜かたわら]**

## [1〜3]

**1 母は（   ）よく音楽を聞いている。**
- a 庭仕事かたがた
- b 庭仕事をするかたわら
- c 庭仕事をしながら
- **[正解: c]**
- **[タグ: ～しながら]**

**2 今回のことでは取引先に迷惑をかけてしまった。（   ）あいさつに行ってこよう。**
- a おわびがてら
- b おわびのかたわら
- c おわびかたがた
- **[正解: c]**
- **[タグ: ～かたがた]**

**3 （   ）神社にお参りしてきた。**
- a 花見がてら
- b 花見かたがた
- c 花見のかたわら
- **[正解: a]**
- **[タグ: ～がてら]**
