# N1文法問題演習

## [1]

**1 必要な学費とあれば、（   ）。**
- a どうか払ってください
- b 父は払ってくれるだろう
- c だれが払うんですか
- **[正解: b]**
- **[タグ: ～とあれば]**

**2 （   ）とあれば、精いっぱい頑張ります。**
- a 日常の家事
- b 車の運転
- c あなたの頼み
- **[正解: c]**
- **[タグ: ～とあれば]**

**3 家族のためとあれば、（   ）。**
- a どんなことをするんですか
- b わたしに何ができますか
- c 彼はどんなことでもするだろう
- **[正解: c]**
- **[タグ: ～とあれば]**

## [2]

**1 あんな人が委員長に（   ）最後、この会はだめになる。**
- a なると
- b なれば
- c なったら
- **[正解: c]**
- **[タグ: ～たら最後・～たが最後]**

**2 彼は怒ったら最後、（   ）。**
- a 次の日にはもう忘れている
- b 怖い顔をする
- c 絶対に許してくれない
- **[正解: c]**
- **[タグ: ～たら最後・～たが最後]**

**3 麻薬は恐ろしいものだ。一度使ったが最後（   ）。**
- a 意志があればやめられる
- b 自分の意志ではやめられなくなる
- c 医者に相談したほうがいい
- **[正解: b]**
- **[タグ: ～たら最後・～たが最後]**

**4 わたしは卵アレルギーなので、卵が入っている食品をうっかり口にしたら最後、（   ）。**
- a すぐに水を飲む
- b 顔中に赤いぶつぶつができる
- c 絶対食べたくない
- **[正解: b]**
- **[タグ: ～たら最後・～たが最後]**

- **[タグ: ～ようでは]**

## [4]

**1 住民の理解と協力なしには（   ）。**
- a この計画は実行できない
- b 不満が多くなる
- c わたしが説得しよう
- **[正解: a]**
- **[タグ: ～なしに（は）・～なしでは・～なくして（は）]**

**2 国の援助なしでは（   ）。**
- a 民間の企業から寄付をしてもらおう
- b わたしはこの研究班を辞める
- c この研究は続けられない
- **[正解: c]**
- **[タグ: ～なしに（は）・～なしでは・～なくして（は）]**

**3 しっかり準備することなくしては（   ）。**
- a いい発表はできない
- b いい発表ができるんですか
- c 発表するのはやめよう
- **[正解: a]**
- **[タグ: ～なしに（は）・～なしでは・～なくして（は）]**

## [5]

**1 結婚して（   ）くらいなら、一人で暮らすほうがましだ。**
- a 自由が欲しい
- b 自由がなくなる
- c 自由がなくなった
- **[正解: b]**
- **[タグ: ～くらいなら]**

**2 わたしは料理が苦手なんです。自分で作るくらいなら、（   ）。**
- a おいしくできるわけがありません
- b 料理教室に行って料理を習います
- c 毎日パンだけでもいいです
- **[正解: c]**
- **[タグ: ～くらいなら]**

**3 わたしはエアコンが嫌いだ。エアコンを入れるくらいなら、（   ）。**
- a 暑くても我慢する
- b 電気代がかさむ
- c 部屋が涼しすぎる
- **[正解: a]**
- **[タグ: ～くらいなら]**

**4 あんな人に頭を下げて頼むくらいなら、（   ）。**
- a 彼はいい気分になるだろう
- b 自分でやろう
- c だれもやってくれないだろう
- **[正解: b]**
- **[タグ: ～くらいなら]**
